# SemanticKG

Локальный редактор интеллект-карт для Windows на C# и WinUI 3. При запуске открывается демонстрационная карта «Запуск продукта». Кнопка **Новая** открывает пустую карту.

## Работа с картой

- **Узел** или `Ctrl+N` создаёт карточку. Перетаскивайте карточки по полотну. Название, заметку, цвет и метки можно менять в панели свойств.
- **Связь** включает режим соединения. Если узел уже выбран, щёлкните по второму узлу. Иначе выберите оба по очереди. Щёлкните по линии, подписи или связи в панели свойств, чтобы отредактировать подпись связи.
- Кнопка `+` рядом с полем **Новая метка** добавляет метку. Слева можно искать по названию и меткам или включить фильтр по конкретной метке.
- **Фокус** показывает выбранный узел и его непосредственных соседей. Колесо мыши меняет масштаб, перетаскивание свободного участка сдвигает карту, а кнопка **Вместить карту** возвращает все видимые узлы в кадр.
- `Ctrl+S` сохраняет карту в локальный файл `.skg`, `Ctrl+O` открывает существующую карту. Файл хранит узлы, координаты, метки, заметки и связи в формате JSON.

## Запуск и сборка

Для готовой сборки Windows x64 запустите `SemanticKG.exe` из папки `bin\publish\SemanticKG-win-x64`. Храните файлы этой папки вместе.

Для сборки из исходников нужен .NET 10 SDK. Выполните в PowerShell из папки проекта:

```powershell
dotnet run
```

Автономная Release-сборка с .NET и Windows App SDK:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -o bin\publish\SemanticKG-win-x64
```
